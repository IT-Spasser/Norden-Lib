![](/assets/norden_lib/banner.jpg)

One NUI menu, one dialog and toast system, one themeable surface, one HUD editor, one HTTP
port — and 40 Lua modules reached through a `norden_lib` global you never declare.

```lua title="fxmanifest.lua"
dependencies { 'norden_lib' }

shared_scripts {
    '@norden_lib/imports.lua',
}
```

```lua
exports['norden_lib']:ShowToast(nil, 'success', 'norden_lib is running', 'Installed correctly.')
```

## What it is not

- **Not a framework.** It detects the framework you already run and normalises what it
  reports — see [`access`](/docs/norden_lib/import-modules#access).
- **Not configured in a file.** There is no `config.lua`. Owners set convars in `server.cfg`
  — see [Convars](/docs/norden_lib/convars).
- **Not invisible when it stops.** A Norden Lib restart takes its consumers' menus with it; they
  re-register when it returns — see the
  [lifecycle adapter](/docs/norden_lib/menu-consumers#shared-lifecycle-adapter-api-v1).

## Requirements

| Requirement | Detail |
| --- | --- |
| Runtime | **FiveM only.** Everything goes through a platform adapter, but FiveM is the only one implemented |
| Install | The **release** zip, not a source checkout — the release carries the built NUI page and server bundle |
| Load order | `ensure norden_lib` **before** any resource that depends on it |
| Framework | None. Norden Lib detects yours; it does not replace it |
| Port | One, `norden_lib_http_port`, default `7777`. Every app Norden Lib serves is a mount on it |
